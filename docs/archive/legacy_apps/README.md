# Legacy Apps Archive

The legacy standalone modules (`apps_architect/`, `apps_exec/`) previously stored in this directory have been compressed into [`docs/archive/legacy_apps.tar.gz`](../legacy_apps.tar.gz) as part of Wave 2 environment and archive hygiene.

To extract:
```bash
tar -xzf docs/archive/legacy_apps.tar.gz -C docs/archive/
```

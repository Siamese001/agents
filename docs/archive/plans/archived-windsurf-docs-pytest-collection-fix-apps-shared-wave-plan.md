## Gap Register

**GAP-1: Missing sys.path.insert in behavioral contract tests**
- Test files generated by ADG testing patterns import from `apps_shared.*` at module level
- Files lack `sys.path.insert(0, str(REPO_ROOT))` before imports
- When pytest collects in certain orders, imports fail with `ModuleNotFoundError`

**GAP-2: Inconsistent path calculation depth**
- Some files use `Path(__file__).parent.parent.parent` (3 levels)
- Newer structure requires `Path(__file__).parent.parent.parent.parent.parent` (5 levels) for tests nested under `tests/unit/apps_shared/`

**GAP-3: Missing `__init__.py` files in apps_shared packages**
- `apps_shared/__init__.py` and `apps_shared/enforcement/__init__.py` were missing
- Python couldn't recognize directories as packages during import resolution

## Rules

1. **Always calculate REPO_ROOT from `Path(__file__)`** — Do not use hardcoded paths
2. **Add `sys.path.insert(0, ...)` BEFORE any `from apps_shared` imports** — Order matters
3. **Use correct parent depth**:
   - `tests/unit/apps_shared/<dir>/`: 5 levels (`parent.parent.parent.parent.parent`)
   - `tests/integration/apps_shared/`: 4 levels (`parent.parent.parent.parent`)
   - `tests/e2e/`: 2 levels (`parent.parent`)
4. **Preserve existing code style** — Match existing imports and formatting
5. **Verify with `--collect-only`** — Every phase must pass collection before proceeding

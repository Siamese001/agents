## Architectural Decisions (carried + new)

### AD-1 (carried from A plan): Keep existing `authority` column for back-compat
The 2026-04-28 commit added `authority` (6-value enum). Removing it breaks already-built consumers. Strategy: keep `authority` as a **derived** column (computed from triplet at backfill time), document it as deprecated, point new consumers to `authority_status`.

### AD-2 (carried): New columns nullable in W1, `NOT NULL` in W6
`bucket`, `resolution_status`, `authority_status` start as `TEXT DEFAULT NULL` in W1 (so backfill is non-blocking) and graduate to `NOT NULL` in P6.3 once `ADG_CERTIFIED` passes for 4 consecutive weeks.

### AD-3 (carried): `evidence_refs` is JSON TEXT
SQLite has JSON1; consumers use `json_extract()`.

### AD-4 (carried): Views are idempotent (DROP+CREATE on every regen)
Same pattern as existing `mv_edges_verified`. Avoids stale-view bugs.

### AD-5 (carried): Existing materialized views become aliases
`mv_edges_verified`, `mv_edges_governance`, `mv_edges_unresolved` keep working but point to `proof_view` / mixed / `risk_view`. Eventually retired post-W6.

### AD-6 (NEW): Spine delegation invariant is structural, not authoring-time
Forbidden mode (`apps_*` standalone mini-runtime) is a structural ADG property. Hooks are wrong tier — author-time cannot tell legitimate enrichment from forbidden re-implementation. Detection happens at commit/CI time as a graph property: every `apps_*/` package MUST have ≥1 import edge into `agentic_core.L[0-2]_*` AND MUST NOT define its own intake-router-executor triple.

### AD-7 (NEW): P4.3 sequenced before P4.6
The P1 handler work sequences before gate rewrites in W4. Otherwise the rewritten gates inherit the same hollow-pass behavior the audit (P4.5) caught.

### AD-8 (NEW): Strict-mode flip is one transaction
P5.1 flips all 4 gates at once, not one at a time. Rationale: any single-gate flip leaves the others advisory and creates a window where the system reports "almost certified" — operationally worse than fully advisory or fully strict.

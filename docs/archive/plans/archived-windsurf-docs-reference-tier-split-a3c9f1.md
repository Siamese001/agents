# Plan: docs/reference/ Tier Split (Option 3, in-tree sentinel folders)

- **Plan ID**: `docs-reference-tier-split-a3c9f1`
- **Status**: Draft (awaiting user approval)
- **Author**: Cursor Agent

- **Type**: Documentation reorg (not code refactoring — no ADG impact)

## Context

`docs/reference/` mixes three content tiers with different authoring rhythms:
- **Tier A — SSOT**: REQ_ID-validated contracts, machine-checked, regenerated by external bundler
- **Tier B — Notes**: hand-authored exec sketches, gap reconciliations, trip reports
- **Tier C — Primers**: neutral technical reference docs (Python, Redis, Testing, ADG, etc.)

The current flat tree causes three failure modes (RCA 2026-04-27):
1. External bundler regenerates `MANIFEST.json` and re-includes Tier B/C files alongside Tier A
2. `_exec` suffix orphans recur because hand-notes live next to canonical SSOT
3. Bulk-WIP commits like `chore: commit all tracked and untracked changes` re-add deleted Tier B files

Option 3 separates tiers via underscore-prefixed sub-folders (`_notes/`, `_primers/`) that mirror the existing `_archive/` convention. Tools already honor `_archive` via `SKIP_DIRS`; extending to the new sentinels is a one-line change.

## Goals

1. Tier A (REQ_ID SSOT) is the only content directly under `docs/reference/<numbered-folder>/` and `docs/reference/00X*.md`
2. Tier B (notes + reports) lives under `docs/reference/_notes/`
3. Tier C (technical primers) lives under `docs/reference/_primers/`
4. `tools/build_parent_thinning_artifacts.py` skips `_notes/` and `_primers/` (so `UPDATED_MANIFEST.json` reflects only Tier A)
5. `check_reference_orphans.py` is tightened to forbid any `.md` at `docs/reference/` root except a fixed allowlist
6. Notion/MCP routing rules and any in-repo references to moved files are updated
7. CI gates green; no broken cross-references

## Non-Goals

- Not changing Tier A REQ_ID content (no doctrine edits)
- Not deleting any file (everything moves; nothing is destroyed)
- Not solving the external-bundler `MANIFEST.json` regeneration (separate Step 3 from RCA — deferred)
- Not touching `_archive/` (already correct)

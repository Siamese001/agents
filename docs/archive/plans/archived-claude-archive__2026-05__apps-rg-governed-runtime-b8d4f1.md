It did NOT produce ANY of:

- FinalEvidenceContract
- CompiledPromptArtifact / PromptEnvelope (the run path didn't invoke RAG)
- SealedL2Artifact

- RuntimeExhaustManifest

Live probe of the candidate substrate (`GovernedRgRun.run_governed_e2e`) under `STRICT_GOVERNANCE=1` failed with `GovernanceContractViolation` due to **3 latent bugs** in the R3 path (`EvidenceShaper` import, `SovereignLLMGateway.generate()` signature, Prompt Assembly `INVALID_CONTEXT_TYPE`) AND wrote 0 artifacts to disk in best-effort mode.

The receipt-writing infrastructure in this codebase (`integrated_runtime_emitter.emit_artifact`, `seal_runtime_exhaust`, `ExitEvalPipeline.run`) is hardwired to the R1B safe-reuse path via `agentic_core/runtime/entrypoints/integrated_safe_reuse_run.py`. There is no symmetric R3 grounded-read entrypoint, no production replay-receipt writer, no production no-bypass-assertion writer, and no UWG durable-write surface for app outputs (apps_rg is explicitly designed without one per `apps_rg/integrations/spine_handoff.py`).

This plan closes that gap.

## Author-Gate trigger points (required before each)

Each of these is an `architecture_choice` decision that must surface an Author-Gate packet before the implementing developer proceeds:

1. **W1 entry — bug archaeology direction.** Three latent bugs need a decision: (a) fix in place; (b) revert to last-known-good API; (c) introduce a compatibility adapter. Author-Gate when each bug's root cause is identified.
2. **W2/P2.4 — CompiledPromptArtifact vs PromptEnvelope canonical name.** Both are already accepted equivalents in `CONTRACT_EQUIVALENT_GROUPS`. Pick one as canonical and demote the other to a typed alias.
3. **W4/P4.1 — L3 managed workflow vs single-L2 packaging of HOP pipeline.** This is the largest single architectural decision in the plan. The HOP pipeline has 10 stages (HOP-0.5 through HOP-5-ATS). Two paths: (A) wrap the whole pipeline as ONE bounded L2 execution unit — easier to land but loses per-HOP audit trail; (B) split into 10 L2 steps under an L3WorkflowContract — preserves per-HOP traceability but multiplies the receipt surface ×10. Surface as Author-Gate before P4.1 starts.
4. **W5/P5.1 — replay model.** Author-Gate to decide: (A) live double-execute with comparison (most rigorous, ×2 cost); (B) deterministic post-hoc re-derivation from RouteContract + evidence_hash + replay_key (cheaper but only catches non-determinism in the route/evidence path, not in model calls); (C) hybrid — post-hoc by default, double-execute on flagged routes.
5. **W6/P6.1 — UWG surface for apps_rg outputs.** Contradicts current `apps_rg/integrations/spine_handoff.py` design intent. Author-Gate to decide: (A) extend UWG to support app-output commits; (B) introduce a separate "ArtifactCommitGateway" parallel to UWG; (C) revise spine_handoff posture and document the new contract.
6. **W7/P7.2 — bootstrap shim removal scope.** Author-Gate to decide whether to remove ALL `_noop` shims in `bootstrap_runtime.py` or only `emit_replay_key`. The blanket `lifecycle.__getattr__ = __getattr__` fallback is a similar bypass — should it go in this wave or be deferred?

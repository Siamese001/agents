# Agentic threat prompts

Evaluate at least:
- prompt/context injection causing unauthorized action;
- confused deputy and delegated-authority abuse;
- malicious or compromised peer agent;
- forged/stale discovery metadata;
- tool schema manipulation or unsafe tool arguments;
- secret extraction through output, logs, memory, or artifacts;
- poisoned RAG or durable memory;
- cross-tenant context or state leakage;
- replay or duplicate execution of high-impact tasks;
- approval bypass and race conditions;
- recursive delegation escaping policy;
- observability gaps that prevent attribution;
- denial of service through unbounded loops/cost amplification.

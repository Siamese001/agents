# Walkthrough Patterns

## Feature flow
Use a directed flow from trigger to outcome. Detail panels explain each major step.

## Architecture map
Place the central platform or domain in the visual center. Arrange experience, orchestration, services, data, and external systems around it.

## Data model
Use entity nodes with labeled relationships. Keep only fields needed to understand behavior.

## Control model
Show action flow separately from governance or control gates. Clicking a gate should explain the policy, decision, or evidence it represents.

## Codebase onboarding
Group nodes by responsibility rather than by folder tree alone. Use file paths as evidence inside details, not as the only organizing principle.

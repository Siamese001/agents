# Cross-skill handoff contract

Execution skills should preserve, when applicable:

- stable object/frame identifiers
- editable source artifact
- rendered preview
- source/provenance metadata
- owner and last-verified date
- unresolved HITL items
- external links separated from secrets
- target-app notes
- rollback or replacement guidance

When the destination cannot be written directly, hand off to `design-handoff-bundle` with the editable source, preview, manifest, QA report, and deployment notes.

# Layout Patterns

## Executive narrative
Hero statement -> evidence visual -> three implications -> decision/action.

## Transformation story
Current state -> tension -> target state -> enabling capabilities -> next move.

## Architecture explainer
System overview -> selectable components -> detail panel -> key controls/decisions.

## Product concept
Problem -> experience concept -> interaction demo -> proof/value -> next step.

## Operating model
Outcome -> capability map -> roles/decision rights -> cadence -> metrics.

Prefer asymmetry and visual focus over uniform tiles. Every section should advance the story.

# Motion Patterns

## Draw-on path
Animate `stroke-dasharray` / `stroke-dashoffset` to reveal a route, dependency, or progress path.

## Pulse
Use restrained scale/opacity pulses to indicate active nodes, controls, or changing state.

## Motion path
Use `<animateMotion>` for tokens, events, or work moving through a pipeline.

## Stage reveal
Fade or translate groups in sequence to teach a lifecycle one stage at a time.

## Feedback loop
Animate a token around a cycle to show sensing, decision, action, and learning.

## Morph
Morph between compatible paths only when the transition itself communicates transformation.

## Reduced motion
Ensure the complete static visual remains understandable without animation.

# Visual Patterns

## Flow
Use a left-to-right or top-to-bottom path with explicit arrows and no crossing connectors where possible.

## Fan-out
Use one visual anchor with branches radiating to multiple outcomes, teams, agents, or channels.

## Convergence
Use several inputs that visibly merge into one decision, platform, synthesis, or outcome.

## Swimlane
Use horizontal or vertical lanes for actors, teams, systems, or governance roles. Keep transitions across lanes explicit.

## Lifecycle
Use a directional sequence with visually distinct phase boundaries. Add gates or controls between phases rather than as detached side notes.

## Control loop
Use a closed path with sensing, decision, action, and feedback clearly placed around the loop.

## Comparison
Use aligned structures with only the dimensions necessary to compare. Highlight the difference, not the decoration.

## Layered architecture
Use nested or stacked regions to distinguish experience, orchestration, services, data, security, and governance layers.

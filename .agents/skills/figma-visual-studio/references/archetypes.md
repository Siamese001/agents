# Governed Executive Archetypes

Executive slides must align to exactly one of the 6 consulting archetypes:

1. **`DIAGNOSTIC_MATRIX`**:
   - Structure: `Observed friction → Business impact → Response`
   - Visual regions: 3–5
   - Evidence rows: 3–5

2. **`RANKED_COMPARISON`**:
   - Structure: Ranked options or issues evaluated against one explicit comparison dimension.
   - Peer items: 3–6
   - Requires explicit comparison dimension header.

3. **`OPERATING_MODEL`**:
   - Structure: `Activities → Handoffs / Ownership → Outcomes`
   - Process stages: 3–6 stages across visual swimlanes.

4. **`ROADMAP`**:
   - Structure: `Phases → Decision gates → Evidence milestones`
   - Process stages: 3–5 sequential phases.

5. **`DECISION_TREE`**:
   - Structure: `Decision branches → Selection criteria → Business implications`
   - Peer branches: 2–4 branches.

6. **`VALUE_BRIDGE`**:
   - Structure: `Current state → Strategic intervention → Realized outcome`
   - Transition steps: 3–5 stages.

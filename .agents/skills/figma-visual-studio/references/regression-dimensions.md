# Regression Dimensions (26 Evaluation Axes)

On revisions (`SURGICAL_PATCH`, `CONTENT_REVISION`), independent reviewers must evaluate the candidate against the exact predecessor across all 26 dimensions:

1. `source_accuracy`
2. `thesis_clarity`
3. `title_quality`
4. `title_readability`
5. `title_size`
6. `title_width_use`
7. `five_second_comprehension`
8. `cognitive_coherence`
9. `visual_hierarchy`
10. `typography`
11. `typography_readability`
12. `spacing`
13. `alignment`
14. `component_consistency`
15. `information_density`
16. `readability`
17. `relationship_clarity`
18. `color_contrast`
19. `icon_graphic_consistency`
20. `reference_fidelity`
21. `visual_polish`
22. `clipping_cutoff_overflow`
23. `raster_quality`
24. `dominant_exhibit_quality`
25. `dead_space_balance`
26. `final_4k_integrity`

## Scoring Rules
- **`IMPROVED`**: Visibly superior compared to baseline at equivalent scale. Required on all declared `improve` target dimensions.
- **`STATIC`**: Preserved without degradation.
- **`MATERIAL_REGRESSION`**: Degraded in any way. **A single regression rejects the entire release.**

# Named Worktree Isolation — stub

> On-demand (historical filename retained). **Invariant:** durable editable work belongs in explicitly chosen registered sibling worktrees on agent-owned, high-signal local branches named `codex-<scope>` or `claude-<scope>` cut from `origin/main`; the worktree folder basename must exactly equal the local branch name (for example `C:/Git/Agentic-Workflow-FRESH-worktrees/codex-worktree-naming-contract` on branch `codex-worktree-naming-contract`). **App-scope segment:** when the work edits files under an `apps_<x>` package (`apps_rg`/`apps_lic`/`apps01`/...), the branch topic must name that app first — `<owner>-apps-<x>-<scope>` (e.g. `claude-apps-rg-competencies-finish`); the app token is the package name with `_`→`-`. Core / `agentic_core` / infrastructure / governance work touches no `apps_<x>` file and needs no app segment (`claude-governance-hooks` stays valid). Never edit the primary checkout while it is on `main`/`master`. **Reuse-first:** reuse the existing named worktree whose workstream matches the task; create a new sibling worktree ONLY when scope materially changes (a different durable workstream), never one per chat and never one per wave. A new wave in the same app/plan/workstream continues in the same branch; use names like `codex-apps-rg-hotspot-tests`, not `codex-apps-rg-wave4-tests`. Slash namespaces (`codex/<topic>`, `claude/<topic>`, `work/<topic>`, `feat/<topic>`) are legacy and must be migrated before further edits; `chat/<timestamp>` is legacy ephemeral and should not be used for new work. SessionStart is advisory only: no automatic per-chat worktree creation and no cleanup. **Delivery/cleanup invariant:** "on main" means exact branch-tip ancestry in `origin/main`; patch-equivalent cherry-picks are not cleanup proof. Superseded/transplanted branches must be recorded with an explicit non-squash ancestry merge (often `git merge -s ours --no-ff <branch>`) before local branch/worktree deletion. Detail: [`worktree-per-chat`](../skills/worktree-per-chat/SKILL.md). Enforced: `before_file_edit_branch_guard.py`; cleanup ancestry gate in `prune_merged_chat_worktrees.py`. Manual cleanup/report: `prune_merged_chat_worktrees.py --dry-run`, then `--delete-merged` only by explicit operator action. Bypass: `WORKTREE_PER_CHAT_BYPASS=1`.
